消息只发送给当前 Agent，在下一次 Model call 前读取。发送时的消息保留原位，读取时在对应 Model call 上方显示回执。你发送的消息靠右显示，Agent 的回信用纯黑背景；这里只展示当前 Agent 的人机消息。

显示分为三档：“只看跟我对话”只看你与当前 Agent 的对话；“看Agent之间对话”再显示它与其他 Agent 的聊天；“看更多细节”还显示模型、工具与读取回执。Agent 对话中 me 代表当前 Agent，others 代表其他 Agent，聊天内容支持 Markdown、公式、代码高亮和图片。新消息不会强制跳到底部，可点右下角“↓ 最新”回到底部。All agents 只汇总消息，依次为“只看跟我对话”“看部分agent对话”“看全部agent对话”；第二项打开筛选，可组合多选发送者与接收者；你发出的消息始终可见。选择“全部”勾选所有项，候选只列你和存活 Agent。消息上的“回复”直接选中发送者并聚焦输入框。@ 只列存活的 Agent，并提供 @all 和 @all（除了 master），群发只发给存活接收者。给停止的 Agent 留言请进入它的单独页面，发送不会自动恢复。

前两档中，可在 Agent 给你的回复前“展开此前细节”，或在你的消息后“展开后续细节”。这些按钮只展开对应消息间的过程，不移动消息；Agent 间聊天卡不设这类按钮。再次点击当前档位，会收起局部展开。

草稿、附件、输入框最大高度、显示档位按当前 Agent 保存，输入区始终可见。可给停止或失败的 Agent 留言及粘贴图片，保存为未读，恢复后读取；发送不会自动恢复。Agent 间新消息在停止状态拒收且不入队；休眠中的新消息仍会唤醒它。

顶部 Stop All 停止整个 Session；Resume Master 只恢复 Master，sub-agent 由 Master 管理。按 Esc 可停止全部 Loops；帮助打开时先关闭帮助。

删除 Session？

将关闭 的运行环境，删除此 Session 的对话、图片快照、设置和日志。此操作无法撤销。

Workspace 工作文件、共享安装包、home 缓存和其他 Session 均会保留。
