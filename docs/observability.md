# 运行观测与统计口径

[文档目录](index.md)

本页定义界面指标的含义。传输异常和对照诊断见 [API 性能](api-performance.md)，原始记录位置见 [存档](session-storage.md)。

## 模型调用与用量

每张 Model call 卡片标明实际模型、耗时和 tok/s，显示 API 回报的 Input、Output、Thinking 与 Cache hit；没有可读思考摘要时不显示空占位。模型返回后在卡片标题下突出显示本步说明，长文可展开；无正文的工具调用使用模型返回的结构化 _step_note 作为本步说明，不由宿主推测动作或补发摘要请求。原始正文与工具参数/签名完整保留；Thinking 独立展示，两者均属于可隐藏细节；给人报告必须显式发消息。

逐调用速度为 API `completion_tokens / Model call 总耗时`。Thinking 不额外再加一次；用量缺失显示未知。模型总耗时包括本调用的重试等待，工具耗时单独记录。Iteration 是 Agent 终身模型调用序号，Resume 不清零；一次启动对应一个 Run。

## Session 累计与输出速度

All Agents 是整个 Session 所有 Agent、所有 Run 的累计量，不因恢复、切页或模型切换清零。缩略状态突出累计 Input / Output tokens，Input 下方显示 Cache hit、命中率和 Non-cache。非缓存 Input 按各调用的 `prompt_tokens − cached_tokens` 相加，包含 context 摘要调用。缺少或不合法的缓存报告单独计为“缓存未报告”，此时 Non-cache 标为已知部分、命中率只针对已报告的 Input，不推测缺失用量。打开已有当前格式 Session 时，服务器按其原始事件重建一次新增缓存统计，不在左栏批量扫描所有历史。展开后查看调用次数、工具、图片、耗时等详细统计。

Output Speed 在同一张图中展示两条曲线，共用时间轴、tok/s 刻度和缩放/平移：模型色细线是逐次调用的 completion_tokens / 该调用总耗时；底层金色细实线是所有 Agent 合计的 10 秒平滑速率，不遮挡逐次调用与点位。Thinking 不重复加。逐次调用按时间相邻连线，模型配色为 Argon 绿、Flash 蓝、Grok 紫。下方提供“最近10分钟 / 最近1小时 / 最近一天 / 全部”，默认最近 1 小时；预设窗口持续跟随当前时间，历史较短时只显示 Session 已有时段。显示窗口不改变合计速率的 10 秒平滑口径。

直接拖图或方向键平移，Ctrl/⌘ + 滚轮或键盘 +/− 缩放。手动操作后进入固定的自定义窗口，隐藏四个选项，不再提供底部滚动条；点击“恢复时间窗口”返回上次的预设并继续自动跟随。Home 恢复“全部”并重新显示选项。

纵轴随当前窗口内两条曲线的最小/最大值自动适配，留少量上下余量；缩放、平移、预设切换和自动推进均会更新。穿过窗口边界的线段按边界插值，窗口外峰值不影响尺度。纵轴不一定从零开始，请以刻度为准；无数据或全零时使用 0–1 tok/s。

Session 合计速率使用 10 秒滑动时间窗：将每个已完成调用的 Output 均匀分配到其调用区间，累加窗口内所有 Agent 的 token，再除以 10 秒（窗口超出已有采样区间的部分按零计）。两 Agent 持续同时各生成 20 tok/s，稳定后的合计约 40 tok/s，不取平均。它是根据完成调用回填的时间平滑估计，不是 API 的逐 token 实时测量；sleep 不算模型生成。

可见页面每秒将预设窗口推进到当前时间，NOW 标记表示当前进度，即使没有新 Model call 也会继续。已知调用之后的合计速率逐渐回落至零，未回报用量的进行中调用不会被虚构为测量样本。首次尚无有效用量时仍显示推进的时间轴，速率为“—”。手动缩放/平移后保留所选历史窗口，底层时间范围继续增长。页面隐藏时暂停绘制，恢复可见后补齐至当前时间。切换窗口不改变累计指标。

## 计时与模型身份

时间使用服务器原始事件 timestamp，按浏览器或终端本地时区显示，不用历史回放时间代替。各模型有独立配色：Argon 绿、Flash 蓝、Grok 紫。切换模型只影响后续请求，历史指标仍属于原调用模型。

HTTP headers、首次模型输出、首次正文和总耗时是不同观测点；SSE 心跳不是生成进度。无重叠耗时依据时，不把这些字段直接相加。完整字段与错误分类见 [API 性能与诊断](api-performance.md)。

工具完整度是另一个独立指标，见 [工具检查](tool-inventory.md)，不能当作模型质量或任务成功率。

## Agent 列表的 token 指标

每个 Agent 行中的 Input 是最近一次正常 Model call 的 `usage.prompt_tokens`，包含 Cache hit，不是该 Agent 的累计输入。“已压缩”显示当前有效摘要使原始历史减少的 token 估算，标记 ≈；原历史与请求投影使用同一个本地估算函数比较，已保留的图片批次、用户要求与近期记录仍计入投影。它不是服务商实际计费量，也不把历次调用或多次压缩的减少量重复累加。成功生成新摘要时替换该估算；原历史不改写。

数字作为 Session 的元数据投影保存，经原 SSE 更新；停止/Resume 后保留，`list_agents` 工具仍只返回其原有的元数据白名单。当前格式存档若缺少数字缓存，只在打开该 Session 时从每个 Agent 最多 512 KiB 的事件尾部恢复可用字段，不扫描完整历史，不参与侧栏目录发现；数据不存在或超出此范围就显示 —。没有压缩且已有观测时显示已压缩 0。
