# 界面行为约定

[文档目录](index.md)

本页是 Web / TUI 维护时的精确行为参考。面向用户的操作见 [Web](guide.md) 和 [CLI](cli.md)，统计定义见 [观测](observability.md)。界面展示不改变模型 context 或队列，所有文件与工具操作在服务器端。

## Web 消息、导航与输入

- Web 导航中每个目录的本层 Sessions 独立分组，置于所有子目录之前，可单独折叠且不影响子目录；置顶不移除所属目录中的条目。普通刷新尊重本层组的手动折叠，新发现本层 Session 或“发现全部”时展开。

- 人机消息醒目且支持 Markdown/公式/代码/图片。每个 Agent 页面只显示该 Agent 自己的人机消息，Master 页不汇总其他 Agent 的报告；查看 Master 不得将 sub 消息标为已读。用户可只看消息了解报告、问题和进展。模型正文、peer 通信及执行过程都属于可隐藏细节，不再显示 Turn/DONE/最终黄线。

- 用户消息保留发送时的展示位置，读取时另加 READ 回执，按实际 input_order 放在消费它的 Model call 正上方，不移动原消息；Agent 发给用户的消息也按发送事件就地展示。人机两方向使用不同的纯色不透明暗背景，不使用渐变。

- 人机卡片使用独立对话样式，用户气泡靠右，Agent 回复纯黑背景。Peer 也用完整图文聊天卡片：当前 Agent 为 me、靠右，其他 Agent 为 others、靠左，明确双方姓名和 Agent 对话标识，纯色暗紫背景与用户输入的暗蓝和回复用户的黑色区分。发送卡在工具成功后原位出现；收信卡在实际接收边界出现，READ 回执单独放在消费它的 Model call 上方，不重复正文。模型正文在实际返回后更新对应 Model call 卡片内的本步说明；用户发送位置与独立消息卡片顺序不改变。

- 当前 Agent 显示默认“看Agent之间对话”，显式偏好按 Session/Agent 保留；共三档：只看跟我对话（基线只看人机消息）、看Agent之间对话（基线再显示 Peer 聊天）、看更多细节（模型/工具/系统/READ 等过程）。前两档保留 toHuman 回复前和真实用户消息后的局部展开按钮，Peer 聊天不添加这些按钮。回复前范围从上一条用户消息到该回复，用户消息后范围到下一条用户消息，新过程可持续加入；重叠区间最后操作优先。局部展开状态按 Session/Agent 隔离，切页/回放保留；选择任一档位（含再次点击当前档位）清除局部展开、恢复该档基线。切换保留阅读锚点或末尾，不移动消息，不改变 context。

- 输入区的草稿、附件、高度和细节开关均按 Session/Agent 隔离，切页恢复各自偏好。输入区始终可见，不再提供收起按钮；成功发送不弹入队提示，失败仍提示。右栏模型/并发/sleep 等 Session 设置与顶部全局生命周期控件不放入输入区。

- 输入区默认约 24px 单行，按内容自动增高，默认 160px 上限后内部滚动；拖动手柄调整的是最大高度，不制造空白固定高度。小号发送键与文本同排，输入提示/帮助、三档显示、运行状态在上方分组排开，窄屏优先保留操作。对话离开末尾时显示“↓ 最新”，点击即时回到底部；切换显示档位无滚动动画。

- Peer 聊天和模型正文复用人机消息的 Markdown/公式/语法高亮/服务器图片渲染，图片不重复显示；不能把它们冒充人机消息。发送参数/投递回执留在全部细节中的工具记录，不重复图文正文；截断的发送参数展开后加载完整内容并更新对应聊天。每次正常 Model call 的 assistant content 是本步简短说明，置于所属 Model call 卡片标题下、Thinking 与用量上方，默认可见；长输出预览约四行、可展开全文，沿用模型配色和完整图文渲染，不在卡片外重复展示。有正文时优先显示正文；正文为空时显示 Worker 从工具 _step_note 参数提取的独立 step_note 字段，按批次去重合并，不改写原始 content。悬停提示区别正文与工具参数来源。正文和说明均缺失时可复用工具 message 参数中的模型正文，明确标记 tool_message 来源；所有来源都缺失则不生成占位说明，运行中的调用不伪造模型文本。API 返回的可读 Thinking 文本（reasoning_content/reasoning/thinking 字符串）独立保留两行紧凑预览，可展开全文；缺失、只有 token 数或只有签名/密文时不占位；两者仍受详情档位及局部展开控制，All agents 仍只汇总消息。展示操作不改变模型 context。

- Python/Bash 工具调用卡标题标明 sync/async，缺省为 sync；长源码截断不丢模式信息，重复事件投影不破坏代码预览。右栏 PROCESSES 显示 Session 当前 run/ready 进程资源，不显示历史和已关闭项；持久进程完成后回到 ready，临时进程完成后移出。按进程计数，同进程 FIFO 排队不重复占行。行内显示当前 Execution 的 sync/async、持久/临时对应的有状态/无状态及本次执行耗时（started_at 到现在；不含排队/进程存活时间）；ready 显示空闲和无当前模式，排队尚未开始时不虚构计时。默认整体折叠，紧凑滚动，底部可拖动/键盘调高。实时更新不强制展开或丢失已读取的输出，换 Session 重置折叠；历史日志不删除。

- 主界面按一次启动 Run 分组，Iteration 为该 Agent 终身模型调用序号，Resume 不重置。Stop 统计为 Run 汇总，右栏 All Agents 为 Session 自创建以来累计，不能在切页/Resume 时清零。

- 右栏 Session Speed 保留每调用 Output/总耗时，并增加全 Session 多 Agent 相加的 10 秒时间平滑 tok/s（不是平均）；历史调用 tokens 均匀分配其调用区间进行滑窗估计，明示估计口径。原各模型配色、时间相邻连线和横向缩放/平移保持。

- All Agents 缩略状态重点显示 Session 累计 Input/Output tokens；Input 旁显示累计 Cache hit/命中率和 Non-cache，后者逐调用 prompt_tokens−cached_tokens 相加，含摘要。缺失/非法缓存报告单独显示未知覆盖，不能当作零命中；打开当前格式存档时一次重建派生缓存统计，导航不加载未打开历史。其余统计展开查看。速度两条曲线同图、共用时间/tok/s 坐标与缩放平移；可见页每秒推进到当前时间，无调用也显示 NOW，合计按已知用量衰减至零，不虚构新样本；手动历史窗口和焦点不被时钟刷新重置，隐藏页暂停、恢复后补齐。

- 速度图不再提供底部平移滑块，提供最近 10 分钟/1 小时/一天/全部四个预设，默认 1 小时；预设每秒跟随当前时间，短 Session 只显示已有时段。手动缩放/平移进入固定自定义窗口并隐藏四个选项；保留“恢复时间窗口”返回上次预设，Home 返回全部。点击图本身不退出预设；新调用/时钟更新不覆盖手动窗口。显示窗口不改变累计用量或 10 秒合计速率的口径。

- 合计速度曲线为底层细实线，逐次调用的模型色曲线与点位于其上；两条曲线与点使用更淡透明度，保留各模型色相。并发上限输入为 0–99 的纯数字文本框，不提供数值步进箭头。

- 左栏工作目录的一级子目录始终默认全部显示；更深层默认只显示含 Session 的分支及必要中间路径，各目录提供 Display/Hide non-session folders 切换本层无 Session 子目录，可见目录都可创建 Session。显示选择按目录隔离，普通目录按需读取直属子目录。启动/刷新发现新增或移动 Session 后自动展开对应路径；无新发现时尊重主动折叠，失去全部 Session 的旧分支自动收起。目录常规字重、柔和颜色和约 22px 紧凑行距，动态同步创建/移动/删除；内部容器和软链接不浏览，未打开 Session 仅轻量元数据，不批量加载历史/图片/日志/摘要缓存。

- 左栏“发现全部”主动重新同步，并展开所有 Session 所在路径和必要祖先，覆盖手工折叠；不展开无关普通分支，不启动/恢复 Agent 或加载全部历史。正在进行的旧轮询完成后再发新请求，切工作目录期间不应用旧根的展开结果。

- 打开工作目录在服务器切导航搜索根，不访问浏览器本地文件系统，不改既有 Agent workspace 或停止后台任务。后台同步不反复显示成功横幅；前台状态显示摘要，详细耗时按需展开。

- 右栏直接从 Session Model 开始，不显示运行现场/连接状态标题行或整个 Runtime 区域；侧栏显隐用主界面顶栏按钮。之后为 Agent 列表、极简累计 All Agents、速度曲线、workspace/Session archive。并发和空闲休眠收进 AGENTS 的默认折叠“设置”面板，点击展开；同 Session 切 Agent 保留开关，切换 Session 折叠。均直接输入数字、无步进箭头；休眠支持小数并校验 0.1–3600 秒。列表上方醒目显示运行中/累计已创建，均含 Master；运行含启动/执行/休眠/停止回收，已创建含停止失败且 Resume 不重复计数。Master 顶部，其后活跃和停止/失败分组，组内创建时间降序；列表内部滚动且高度可调。顶部 TAB 保留 Master、活跃 sub、当前停止 sub；Master 独立固定，约 22px 高/160px 宽，两行后纵向滚动。

- 时间取服务器原始事件 timestamp，浏览器本地时区显示，不以回放时间代替。回放批量更新右栏，禁止逐事件读滚动布局；HTTP 大 JSON/静态资源协商 gzip，SSE 不缓冲。

- 人机新消息通知支持鼠标/键盘打开，切换到来源 Session/Agent 并聚焦具体 message_id；按需加载早期历史，保持消息原位和细节偏好，不仅跳到末尾。

- 新消息到达、用户/系统消息被读取、模型/工具更新都不能强制滚到末尾；保留当前阅读位置，打开页面和用户主动“↓ 最新”仍可到底部。新消息提示位于对话区 Agent tabs 下方，正常布局，不覆盖或夺取输入焦点。

- 顶部 All agents 是消息投影视图，不是 Agent，不创建 context/worker/额外 SSE。按时间分页读取 Session 的持久人机/peer 消息，排除 System、模型正文和工具细节；不消费收件箱、不读模型 context。“只看跟我对话”“看部分agent对话”“看全部agent对话”三项依次并列，第二项打开发送者/接收者多选面板，同栏取或、两栏取且，只有该档应用筛选。候选仅你和存活 Agent；全部时每项勾选，你发的消息无条件可见。无局部展开或 loop 卡片。每条 Agent 消息可回复并选中发送者、聚焦输入；停止项转单 Agent 留言，不唤醒。自己的消息可继续给原接收者发送。图文使用实际资产所属 Agent 的受限图片接口，同一批群发在该视图合并展示但保留各接收者消息 ID；草稿/显示档位/筛选/@接收者按 Session 的 all 视图独立保存。

- All agents 中发送者头像及署名可跳到该 Agent tab 的原消息，按持久 message ID（群发为全部接收者 ID）匹配；按需加载早期历史，不只滚到末尾，不启动/恢复 Agent。隐藏的 peer 目标单独临时可见，不改保存的显示档位；重选档位清除此展示例外。快速切页/再次定位时旧异步定位不能覆盖新选择。

## TUI

- TUI `/resume` 按本层 Session、返回上一级、直属子目录排列；Session 金色 ◈、目录蓝色 ▱，选中仍保留分类色，子目录不附操作说明。支持进入子目录/返回上级，取消递归与 Ctrl+R，菜单上下键到边界停住、不循环；目录列表只查轻量元数据，不加载历史、不启动 Agent；直接指定存档路径可定位子目录。Shell list 保留递归查找。

- 终端 chat/attach 使用真正全屏 TUI：滚动消息区在上，输入框常驻底部，@、/、Agent 列表与设置等面板在输入框下方；消息到达不得抢输入焦点。三类消息分色并支持 Markdown/引用/表格/代码高亮，输入默认一行、最多五行；不展示 loop 卡片。Rich 只将可信样式转换为 prompt_toolkit fragments，禁止用 patch_stdout(raw=False) 直接打印 ANSI。后端调用/队列读取在后台，UI 只读缓存；滚离底部后保留阅读锚点并显示最新提示。JSONL/非 TTY 保持原 Shell 协议；Core/Web 不依赖 TUI 库。

- TUI 交互约定：只有 `/stop` 命令可发起停止，不提供 Esc/Ctrl+C Stop、顶部 Stop 按钮或任何功能键管理入口；Esc/Ctrl+C 仅关闭面板并保留草稿。Ctrl+D 随时正常退出，与 `/quit`、`/exit` 共用退出流程，不发送草稿；关闭当前 Session 并释放 Host 独占，包括 attach 的后台 Session。Agent 列表、显示范围、设置和帮助均通过 `/agents`、`/messages`、`/settings`、`/help` 等命令。Web 的全局 Stop 规则保持独立。人机卡片明确标记“你发出的消息”/“给你的消息”，后者黑底金色双线框；Peer 为内缩暗紫细框并标记“Agent 对话 · 内部通信”，同时靠边框/位置/文字区分，不能仅依赖颜色。

- TUI `/resume` 专用于恢复/选择 Session，无参数列出当前搜索根下的轻量存档，支持名字/ID/路径；唤醒当前 Master 使用 `/wake`。`/wake` 在停止/失败时重建 Master，休眠时通过真实用户消息队列唤醒，运行中不重复启动，不恢复 sub。Session 切换保留各自草稿、附件、显示范围和阅读位置，但先关闭旧 Session，再 Resume 目标；一个 CLI 不保留多个后台 Session。Web 所有权锁继续生效，Core 不依赖此导航层。

- TUI `/speed` 在输入框下方显示整个 Session 全 Agent 的输出速度双曲线，与 Web 同口径：API completion_tokens/完整调用耗时，以及并发相加的10秒平滑估计；Thinking 不重复计数，缺失用量不虚构。模型配色保留，Model call 只画散点不连线，合计仍保留底层曲线；默认1h，可用 /speed 10m/1h/1d/all/wider/narrower/in/out/left/right/reset/off。速度图打开、无菜单、输入框为空时 ← 扩大最近时间窗口、→ 缩短窗口，并持续跟随现在；有草稿时左右键仍编辑文本。每秒推进当前窗口并按可见数据缩放纵轴，手动窗口不被时钟重置。只在打开时拉取当前 Session 的数值观测，不读 context、不消费队列、不触发模型/工具，不为导航扫描历史；图表与统计格式在 Apps，Session 只提供数据投影。

- CLI 默认 chat 未指定存档时，先显示 NoSessionClient 的空白输入界面，不创建 Session、不启动 Host/Agent、不读模型配置；首条真实消息发送时再检查凭据、创建存档、唤醒 Master、经持久队列投递。帮助、草稿、目录选择和 Ctrl+D 退出不能创建 Session。命令行 -p/--prompt-file/--image 算首条消息；显式 create、已有存档的 resume/chat -s 仍按明确请求执行。新建 run/后台 chat 没有首条消息时拒绝自动创建。Stop 返回空白界面后也可通过新消息开始新的 Session。

- TUI 底部提示只展示当前有效且最有用的操作；空白无 Session 时提示首条输入和 /resume，不提示 /stop；无可见面板/菜单时不显示 Esc。面板、后台压缩状态、测速图、草稿、失败重试和历史阅读分别使用对应提示，不抢输入焦点。

## 连接与运行边界

启动时的上次 Session 选择只是浏览器偏好：优先用当前同步结果中的持久 ID 定位，找不到时可由服务器校验已保存的存档路径。存档不存在、路径失效或格式不兼容只清除浏览器选择并提示重新选择，不撤销已完成的目录同步，不重建旧目录、不迁移或改写真实存档。仍有效的根外存档继续支持只读打开。权限、占用、连接错误保留记录并显示为 Session 恢复失败；真正目录扫描失败仍显示工作目录同步失败。

Web 的普通存档打开和消息定位默认 browse，不启动 Agent。停止存档的恢复提醒覆盖输入区，Resume 前禁止编辑和发送；已有本地草稿保留，Resume 成功后恢复输入。运行 Session 内给停止 Agent 留言仍可用。Session Model、并发和兜底 sleep 是 Session 设置；草稿、附件、显示档位与局部展开按 Session / Agent 隔离。只读存档的设置只暂存，成功 Resume 后才提交。

同页最多一个 SSE，sub 共用 Session 订阅；隐藏页释放连接并暂停轮询，恢复后补齐事件。新实例撤销旧文档请求，页面回放批量更新右栏，不逐事件读取滚动布局；大 JSON/静态资源协商 gzip，SSE 不缓冲。GUI 接管、文档代际与 Host 锁见 [Host 协议](session-ownership.md)。

- 右栏 Agent 行移除创建时间文字，仍保持 Master 顶部、活跃/停止分组及组内创建时间降序。紧凑显示最近一次正常 Model call 的 API Input 和“已压缩”的 token 量估算；完整数值与口径放悬停提示，缺失显示 —。用量更新不改变排序、选中项或滚动位置。

Resume Master 提示出现时始终覆盖输入表面，适用于只读浏览、Host 仍持有但 Master 已停止或失败的状态。输入框、接收者与发送操作同时禁用，保留未发送草稿；提示随输入高度及窗口宽度调整，Resume 按钮保持可操作，成功恢复后解除覆盖。
